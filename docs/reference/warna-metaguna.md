# Acuan warna Metaguna

Sumber: https://www.metaguna.ac.id/, diperiksa melalui computed style browser pada 24 Oktober 2026. Warna diambil dari elemen yang tampil, bukan dari pedoman merek resmi.

| Peran | Nilai | Bukti pada situs |
| --- | --- | --- |
| Teal utama | #00758D | Judul bagian fakultas dan tautan teknologi. |
| Teal gelap | #003E51 | Teks penekanan situs. |
| Merah | #C23325 | Tombol Join Intake 2027 dan judul program kreatif. |
| Oranye | #FF9A2D | Latar tombol Unduh Brosur. |
| Teks sekunder | #696F80 | Warna teks body. |
| Latar | #FFFFFF | Latar body. |
| Permukaan | #F7F7F7 | Latar beberapa bagian. |

Diagram memakai #FAFAF7 sebagai kertas, #003E51 sebagai tinta utama, #00758D sebagai aksen, #696F80 sebagai teks sekunder, dan #F7F7F7 sebagai permukaan. Garis relasi menggunakan teal gelap. Oranye dipakai untuk contoh palet, bukan teks kecil. Latar putih situs disesuaikan sedikit agar batas gambar terbaca pada halaman putih.

Situs memakai Inter untuk judul dan Roboto untuk body. Kedua keluarga terdeteksi dimuat pada browser. HTML menggunakan Google Fonts dengan keluarga yang sama. Label teknis memakai monospace sistem sebagai fallback yang dinyatakan, karena tidak ada font teknis yang terdeteksi pada situs. Ekspor SVG dan FigCraft menggunakan Arial untuk portabilitas jika font situs belum terpasang. Permintaan warna tetap dipertahankan pada semua format.

Profil ini disimpan dalam proyek. Tidak ada perubahan pada profil warna global atau file skill yang terpasang.
